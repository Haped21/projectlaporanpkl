🚀 Langkah Setup Firebase
1
Buat Project Firebase
Buka console.firebase.google.com → klik "Add project" → beri nama (mis. simpal-kai-daop8) → selesaikan wizard.
2
Aktifkan Firestore & Storage
Di sidebar Firebase: Build → Firestore Database → Create database → Start in test mode.
Lalu Build → Storage → Get started → mode test juga.
3
Salin Firebase Config
Project Settings ⚙️ → Your apps → klik ikon Web (</>) → Register app → salin objek firebaseConfig.
4
Tempel config ke file HTML
Buka file simpal-kai-firebase.html dengan editor teks, cari blok CONFIG di bagian script, isi nilai-nilainya:
const FIREBASE_CONFIG = { apiKey: "AIzaSy...", authDomain: "nama-project.firebaseapp.com", projectId: "nama-project", storageBucket: "nama-project.appspot.com", messagingSenderId: "123456789", appId: "1:123456789:web:abc..." };
5
Deploy ke VPS
Upload file HTML ke web server (Apache/Nginx). Akses dari browser — sistem siap digunakan. QR scan akan bekerja dari URL publik server Anda.
